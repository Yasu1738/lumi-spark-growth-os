# 毎日の自動更新手順（スマホ版）

オーナー了承：2026-10-24（RSSの取り込み、タイトルからのテーマ・タグ推定、関連記事の自動提案。承認は人が行う）

毎朝 6:47（日本時間）に、Claude Code のこのセッションへ予約メッセージが届き、次を行う。

対象ページ：https://claude.ai/artifact/ViGffCC5QJiyqNcvjQ9JMX

## 手順

1. スマホ版のデータを読み出す（ArtifactData `list`、`out_dir` 指定）
   - `articles` / `links` / `hubs` を同じフォルダ（例：scratchpad の `daily/<日付>`）へ
   - 一覧に表示された各記事の版番号を `versions.json`（`{"LS-A001": 3, ...}`）に保存する
2. RSSを取得し、計画を作る（まず推定なしで実行し、`needs_estimate` を確認）
   ```bash
   python scripts/mobile_sync.py --dump <フォルダ> --out <フォルダ>/out
   ```
3. `needs_estimate` に記事があれば、タイトルからテーマ（ORG/AI/MKT/REG/FIN/EVENT/META）とタグを推定して
   `estimates.json`（`{"LS-A035": {"theme": "ORG", "topic_tags": "組織づくり,リーダーシップ"}}`）を作り、
   `--estimates` を付けてもう一度実行する。タグは既存記事・ハブで使っている語（下記）を優先する。
4. 出力された `batch_*.json` を、ArtifactData `batch` で順に書き込む。
   版番号の不一致で拒否されたら、その日の作業を最初からやり直す（人の編集を上書きしない）。
5. 結果を1〜2行で報告する。新しい記事も提案もなければ「新着なし」とだけ書く。

## してはいけないこと

- 記事ページの読み取り（RSS以外へのアクセス）
- 人が入れたテーマ・タグ・タイトルの上書き（`mobile_sync.py` は空欄のみ埋める）
- リンクの承認や「貼った」の記録（人が行う）
