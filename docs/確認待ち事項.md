## 2. 人間の判断・承認が必要な事項

1. **9件のリンク提案（LNK-0001〜0009）の確認と承認**：すべて仮案です。URL・本文確認がそろったものから「確認→承認」へ進めてください。推薦はタグからの機械的な推定です。

3. **構造コードの付与**：実記事にはT/H/V/Cコードを設定していません（筆者の判断が必要なため）。
4. **noteへの反映**：承認後、noteの編集画面でのリンク設置は人が行い、アプリで「note反映」「表示確認」を記録してください。

6. **収益導線の設計**：各記事をどの段階へつなぐか、メンバーシップの案内をどの記事に置くか。
7. **バックアップの保管場所**：`backups/` の外部コピー先。
