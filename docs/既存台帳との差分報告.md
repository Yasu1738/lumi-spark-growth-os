## 3. 本システムで新たに持つ項目

タイトル確認状態、URL確認状態、本文確認済み、タイトル構造コード（T01〜T10、複数可）、Human（H0〜H3）、Perspective Shift（V0〜V3）、Specificity（C0〜C3）、導線段階（7段階）、収益導線、関連テーマタグ、仮説判定、情報の出典、確認状態、データ区分（実データ／サンプル）、IMP、有意味コメント、相談件数、メンバーシップ参加数、計測区分と公開後経過時間、ハブ、関連記事リンク提案と承認状態、操作履歴、読者理解（コメントタグ・元仮説への影響）。

## 4. 書き戻しについて

本システムから既存台帳へ書き戻す機能はありません。台帳に反映する場合は、「書き出し」で作ったExcelを参照し、人が台帳へ転記してください。
